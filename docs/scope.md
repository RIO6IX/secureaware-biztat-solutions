# SecureAware Scope

## In Scope
- Responsive web application for Employee, Department Manager, Security/HR Admin and System Admin roles.
- Login, logout, RBAC, audit logging, SQLite persistence and backup/restore.
- Policy management on `sanduni`.
- Security training and quiz assessment on `chanuka`.
- Compliance status, reminders and CSV export as shared foundation work.

## Out of Scope
- Production Biztat identity provider integration until approved.
- Real employee data until provided through an authorized, non-confidential process.
- Native mobile apps.
- Legal certification or ISO certification claims.

## Roles
- Employee: complete assigned policies and training.
- Department Manager: review department compliance.
- Security/HR Admin: manage policies, training, assignments and reports.
- System Admin: manage technical settings and backups.
