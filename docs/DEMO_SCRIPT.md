# Demo Script

1. Security/HR Admin signs in.
2. Admin reviews audit logging and role controlled access.
3. On `sanduni`, admin publishes and assigns a policy.
4. Employee acknowledges the displayed policy version.
5. On `chanuka`, employee completes assigned training and submits a quiz.
6. Manager or admin reviews compliance status.
7. Team explains password hashing, sessions, RBAC, privacy, audit logging and backup.
